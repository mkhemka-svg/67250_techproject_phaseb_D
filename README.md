# 67250_techproject_phaseb_D

Key Points of Consideration: 
1. The following error message comes up in the console sometimes when the website is loaded: “Unsafe attempt to load URL file:///.../explore.html from frame with URL file:///.../explore.html. 'file:' URLs are considered unique security origins.” This is not a bug in the project. Instead, it is due to browser restrictions on loading HTML pages using the local file protocol. Instead, launch a local development server with the command python3 -m http.server 8000 and visit http://localhost:8000 or use any standard website hosting provider like GitHub Pages so this error does not occur.

2. The final project was deliberately put at the root level of the repository directory, such as index.html, views/, and static/, instead of under a subdirectory name “final-project” (as required in the project instructions). This is because at the development stage, having the project in a subdirectory resulted in a problem with relative file paths preventing CSS, JavaScript, and images from being accessible and also, I could not deploy the site through GitHub Pages. By keeping the project at the root level, both issues were fixed, and the site deployed successfully on GitHub Pages from the main branch. Hence, the final project is just the code in the folders “static” and “views” and the file “index.html” in the root level.
